# Contributing to SwiftCommit

Thank you for your interest in contributing to SwiftCommit! We welcome all contributions, whether it's reporting bugs, suggesting improvements, or submitting code changes.

## Getting Started

### 1. Fork the Repository
1. Click the "Fork" button at the top right of the repository.
2. Clone your fork:
   ```sh
   git clone https://github.com/your-username/SwiftCommit.git
   cd SwiftCommit
   ```

### 2. Create a New Branch
- Always create a new branch for your changes.
- Use a descriptive name:
  ```sh
  git checkout -b feature-new-button
  ```

### 3. Make Your Changes
- Ensure your code follows project standards.
- If adding new features, update the documentation accordingly.

### 4. Commit and Push Changes
- Follow [Conventional Commits](https://www.conventionalcommits.org/) for commit messages:
  ```sh
  git commit -m "feat: add new feature to generate commit messages"
  git push origin feature-new-button
  ```

### 5. Submit a Pull Request (PR)
1. Navigate to the **original repository** on GitHub.
2. Click **New Pull Request**.
3. Select your branch and submit the PR.
4. Provide a clear description of your changes.

## Reporting Issues
- Use the **Issues** tab in GitHub to report bugs or suggest improvements.
- Provide as much detail as possible, including steps to reproduce.
